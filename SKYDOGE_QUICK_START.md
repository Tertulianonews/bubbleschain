## 🐛 Problemas?

### Canal não aparece?

- Execute o SQL novamente no Supabase
- Use pull-to-refresh na tela de canais
- Verifique se há usuários cadastrados

### Erro ao abrir?

- Reinicie completamente o app
- Verifique se todos os arquivos foram criados
- Execute `flutter clean` e `flutter pub get`
